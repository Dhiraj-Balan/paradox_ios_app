# PARADOX

An iOS investment platform app built with SwiftUI, featuring a modern glassmorphism and neon UI.

## Features
- Login screen with authentication flow
- Investor dashboard
- Reusable UI components (GlassCard, NeonButton)
- Centralized theming with ThemeManager
- App routing between screens

## Tech Stack
- Swift
- SwiftUI
- Xcode

## Project Structure
    ParadoxApp/
    ├── Auth/        (AppRouter, LoginView)
    ├── Investor/    (InvestorDashboardView)
    ├── Shared/      (GlassCard, NeonButton)
    ├── ThemeManager.swift
    └── ParadoxApp.swift

## Getting Started
1. Clone the repo:

        git clone https://github.com/Dhiraj-Balan/paradox_ios_app.git

2. Open the project in Xcode
3. Select an iOS simulator
4. Press Run (Cmd + R)

## Requirements
- macOS with Xcode 15 or later
- iOS 17 or later
